## 主格 屬格 賓格


|     | 單        | 復          |
| --- | -------- | ---------- |
| 主格  | Domin-a  | Domin-ae   |
| 屬格  | Domin-ae | Domin-árum |
| 賓格  | Domin-am | Domin-ás   |

Fília agricolae nautam amat. 農民的女兒喜歡水手。

## 與格

日本語の「に」に相当する。

若主格單數以-a結尾，與格單數詞尾為-ae，復數爲-ís

Nauta agricolís fugam núntiat

## 奪格

若主格單數以-a結尾，奪格單數詞尾為-á，復數爲-ís。表分離趨勢的來源，工具，或場所。

拉丁語介詞管的名詞必須是賓格或奪格。

奪格介詞有
- á, ab 從，遠離
- cum 和
- dé 從
- in 在...中
- é, ex 從，從...出來

## 第二類名詞變格 (o-變格)

- 主格單數以-us，-er，-ir或-um，結尾，屬格單數均以-í結尾。
- -um結尾的為中性，其他為陽性。

|        | 單           | 複          |
| ------ | ----------- | ---------- |
| 主 nom. | domin-us    | domin-í    |
| 呼 voc. | **domin-e** | domin-í    |
| 屬 gen. | domin-í     | domin-órum |
| 與 dat. | domin-ó     | domin-ís   |
| 賓 acc. | domin-um    | domin-ós   |
| 奪 abl. | domin-ó     | domin-ís   |
