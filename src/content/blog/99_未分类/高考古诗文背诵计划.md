# 高考古诗文背诵计划

## 复习方法

每篇按以下顺序练习：

1. 先回忆论证结构或段落顺序。
2. 再根据助记词还原每句开头。
3. 合上原文，完整背诵或默写。
4. 想不起来时先留空，全文完成后再对照订正。
5. 只重背错句和衔接处，不要一直重读整篇。

### 间隔复习

- 首次背诵后 10 分钟：无提示背诵一次。
- 当天睡前：只看段首或助记词，尝试还原全文。
- 第 2 天：完整默写，建立易错词清单。
- 第 3 天、第 7 天：各做一次无提示默写。
- 以后每周：与其他篇目交错抽查。

## 《论语》十二章

### 顺序助记词

> 食、仁、朝、义、贤、质；士、山、知；颜、恕、诗。

### 原文开头

1. **食**：君子食无求饱
2. **仁**：人而不仁
3. **朝**：朝闻道
4. **义**：君子喻于义
5. **贤**：见贤思齐焉
6. **质**：质胜文则野
7. **士**：士不可以不弘毅
8. **山**：譬如为山
9. **知**：知者不惑
10. **颜**：颜渊问仁
11. **恕**：子贡问一言，孔子答“恕”
12. **诗**：小子何莫学夫《诗》

### 分组结构

> 六项修养 → 三项担当 → 颜仁、贡恕、学诗。

- 前六章：好学 → 仁 → 道 → 义 → 见贤 → 文质。
- 中间三章：弘毅 → 坚持 → 智仁勇。
- 最后三章：颜渊问仁 → 子贡问恕 → 小子学《诗》。

## 《劝学》

### 论证地图

> 学习不能停 → 学习能改变人 → 学习要善于借力 → 学习贵在积累、坚持、专一。

### 全文助记词

> 已；青冰木绳金省；思望招呼马舟；山水善、步流、骐驽锲、蚓蟹。

### 第一段：中心论点

- **已**：君子曰：学不可以已。

### 第二段：学习能改变人

> 青 → 冰 → 木变弯 → 木变直 → 金变利 → 人参省。

- **青**：青，取之于蓝，而青于蓝。
- **冰**：冰，水为之，而寒于水。
- **木**：木直中绳，𫐓以为轮，其曲中规。虽有槁暴，不复挺者，𫐓使之然也。
- **绳**：木受绳则直。
- **金**：金就砺则利。
- **省**：君子博学而日参省乎己，则知明而行无过矣。

### 第三段：善于借力

> 思望；招—臂—见，呼—声—闻，马—足—里，舟—水—河。

- **思**：终日而思 → 不如须臾之所学。
- **望**：跂而望 → 不如登高之博见。
- **招**：臂非加长 → 见者远。
- **呼**：声非加疾 → 闻者彰。
- **马**：非利足 → 致千里。
- **舟**：非能水 → 绝江河。
- **结论**：君子生非异也，善假于物也。

### 第四段：积累、坚持、专一

- **山水善**：积土成山、积水成渊、积善成德。
- **步流**：不积跬步，无以至千里；不积小流，无以成江海。
- **骐驽**：骐骥一跃，不能十步；驽马十驾，功在不舍。
- **锲**：锲而舍之，朽木不折；锲而不舍，金石可镂。
- **蚓蟹**：蚓用心一，蟹用心躁。

### 已发现的易错点

- **见者远** / **闻者彰**：不要交换。
- **声非加疾也**：是“疾”，不是“急”。
- **假舟楫者**：是“楫”，不是“辑”。
- **则知明而行无过矣**：是“则”，不是“而”。
- **下饮黄泉，用心一也**：不要漏掉“用心一也”。
- **蛇鳝之穴**：是“鳝”，不是“蟮”。
